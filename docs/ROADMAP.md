# Worldline · 路线图

## 分阶段总览

**每个阶段有硬性出口标准，不达标不进入下一阶段。**

| 阶段 | 内容 | 出口标准 |
|---|---|---|
| **P0 地基** | git / LICENSE / Vite+React+TS(strict) / ESLint / Prettier / Vitest / CI / PROGRESS.md / docs | `npm run check` 全绿，CI 通过，空页面可渲染 |
| **P1 数据层** | `types/source.ts` 定型 / zod schema / radioBrowser（镜像轮询 + 重试 + IndexedDB 24h 缓存）/ weather / time | 3000 个带坐标电台 + 任意城市天气时区；核心路径单测覆盖；镜像失败顺延测试通过 |
| **P2 球体** | 程序化纸质贴图 / 球体 + 黄铜环 + 木底座 / 桌面 + 光照 + 投影 / 后期处理 | `/dev/globe` 截图可直接当壁纸；稳定 60fps |
| **P3 图钉** | `InstancedMesh` 图钉 + raycasting / 拖拽旋转 + 惯性 / hover 提示 | 3000 图钉 ≥50fps；点击命中准确率 100% |
| **P4 音频** | 单 audio 复用 + `GainNode` 淡入淡出 / 容错跳台 / 频谱 | 连切 20 台不断音不爆音；坏台自动跳过；状态机单测覆盖 |
| **P5 降落** ⚠️ | 降落时间轴 / **纸面→实景 shader** / 城市视觉 / 信息卡 | 客观指标全达标 + 主观评分 ≥4；过渡无跳变无闪烁 |
| **P6 收尾** | 侧栏 / 搜索 / 收藏 / 壁纸预览 / README + GIF | 组件测试通过；`gh repo create worldline --public` 并推送 |

## P5 验收标准

**客观**

1. 点图钉 → 出声 ≤ 3s
2. 降落动画 2.5–4s，纸面→实景过渡无跳变、无闪烁
3. 3000 图钉下稳定 ≥ 50fps
4. 选定城市可播率（http + https）≥ 60%
5. 连续降落 10 城不崩、无内存泄漏

**主观（真正的判据）**

6. 找 3–5 人看 30 秒，答「有没有到那儿的感觉」（1–5），均值 ≥ 4
7. ≥ 2 人**主动**说「想一直开着」

> 客观指标全绿但主观不达标 → 这个方向要重新想。

## 质量保障

### 性能预算（每阶段实测，填进 PROGRESS.md）

| 指标 | 预算 |
|---|---|
| 帧率（3000 图钉，中端核显） | ≥ 50fps |
| 冷启到首帧 | < 2s |
| 降落动画帧率 | 稳定 ≥ 50fps |
| 首屏 JS（gzip，不含 three） | < 300KB |
| 内存（连降 10 城后增长） | < 50MB |

### 测试分层

| 层 | 工具 | 覆盖 | 不覆盖 |
|---|---|---|---|
| 单元 | Vitest | 纯逻辑：镜像轮询 / 字段映射 / 时间计算 / 音频状态机 / 缓存 | UI、3D |
| 集成 | Vitest + MSW | 数据流：API → zod 解析 → 缓存 → store | 渲染 |
| 组件 | Testing Library | 侧栏 / 搜索 / 信息卡交互 | 3D 场景 |
| 视觉回归 | Playwright 截图对比 | 地球仪场景、降落关键帧 | 逐像素 |
| 手动 | 检查清单 | 性能、音频、主观体验 | — |

**覆盖率目标：纯逻辑层 ≥80%，整体不设硬指标**（避免为了凑覆盖率写垃圾测试）。

### CI 门禁

每次 push / PR 跑 `typecheck → lint → format:check → test → build`。全绿才允许合并。

视觉回归只在手动触发时跑——截图对比在 CI 环境上不稳定，不要让它变成噪音。

### 降级开关

| 特性 | 降级方案 |
|---|---|
| shader 纸面→实景混合 | 退化为硬切 + 0.6s 交叉淡入 |
| 阴影 | 关掉 shadow map，改用假投影贴图 |
| 后期处理 | 一键关闭 |
| 频谱可视化 | 流无 CORS 头时不驱动，只显示静态波形 |
| Commons 城市照片 | 退化为纯 GIBS 瓦片 + 信息叠加层 |

**原则**：出问题能一键关掉，而不是回滚代码。

### 提交规范

- **Conventional Commits**：`feat` / `fix` / `refactor` / `test` / `docs` / `chore`
- 阶段完成打 tag：`v0.1-p0`、`v0.2-p1` …

## 风险清单

| # | 风险 | 缓解 |
|---|---|---|
| 1 | **P5 纸面→实景 shader 调不好**，比朴素写实地球更难看 | 色彩归一化；混合带噪声扰动；硬切降级开关；预留充足时间 |
| 2 | **实体地球仪性能**，低端核显可能掉帧 | 图钉 `InstancedMesh`；阴影贴图 1024；后期可关；贴图 2048 兜底 |
| 3 | **坐标覆盖率仅 17%**，分布极不均 | 接受为特性；补「无坐标电台」第二入口 |
| 4 | **Windows 动态壁纸无官方 API**，系统更新易破坏 | P7 先用静态壁纸；动态壁纸作实验特性，失败降级为置底全屏窗口 |
| 5 | **电台质量不可控**，打断"在场幻觉" | 自动跳到下一个可用台；优先 `lastcheckok=1` + 高票台 |
| 6 | **新鲜感衰减** | 留存靠漂流模式 + 收藏 + 旅程日志，P8 尽快接上 |
| 7 | **版权**（Commons 逐图 CC、电台流转发邻接权） | 地图贴图程序化生成；优先 GIBS + Commons 并标注；商用前逐项复核 |
| 8 | **API 稳定性** | 镜像轮询 + 重试 + IndexedDB 缓存 24h |
| 9 | **无后端的代价**，收藏只在本机 | 早期视为优势；P9 再接可选云同步 |
| 10 | **范围蔓延** | 严格按阶段推进，出口标准不达标不许开下一个机制 |
