# Worldline · 视觉规范

## 核心隐喻

**写实地球 = 工具感**，你在"查看"世界。
**实体地球仪 = 物件感**，你**拥有**世界——它是你书桌上的一件摆设。

> **世界从我的桌上展开成了我的屏幕。**

## 三个状态

| 状态 | 画面 |
|---|---|
| **探索态** | 地球仪摆在桌面上。黄铜子午环、木质底座、哑光纸质地图贴面、插在地球上的黄铜图钉。磁倾 23.5°。斜上方 45° 视角，能看见桌面和投影。可拖拽旋转。 |
| **降落中** | 相机推进到贴近球面。球面材质由纸质地图逐渐混合成真实城市影像（自定义 shader 按相机高度 mix）。桌面与投影逐渐淡出。 |
| **沉浸态** | 球面完全被实景填满 = 桌面壁纸。信息卡滑入，整个屏幕就是那座城市。 |

返回时反向播放。**"一个小物件展开成整个屏幕"的反差，是这个产品的核心冲击力。**

## 配色

| 用途 | 值 | 说明 |
|---|---|---|
| 背景（暗） | `#14110e` | 暖黑，不是纯黑 |
| 桌面 / 面板 | `#1d1916` | |
| 边框 | `#322b26` | |
| 正文 | `#efe8e1` | 暖白 |
| 次要文字 | `#9a8f86` | |
| **黄铜** | `#c9963f` | 品牌色。用于图钉、子午环、强调元素 |
| 纸面 | `#e8dfd0` ~ `#f2ebdd` | 地球仪贴面底色 |
| 墨线 | `#3a3632` | 海岸线、经纬网 |
| 图钉红 | `#c0392b` | 与黄铜形成对比，但不要荧光 |

**整体基调：暖、哑光、有质感。** 禁止霓虹、禁止高饱和渐变、禁止玻璃拟态。

## 材质与光照

| 部件 | 材质 |
|---|---|
| 球体 | `MeshStandardMaterial`，roughness 0.9，metalness 0。哑光纸感，**不要反光** |
| 黄铜子午环 | metalness 1.0，roughness 0.35。唯一的金属高光点 |
| 木质底座 | 程序化木纹贴图，roughness 0.7 |
| 桌面 | 深色木纹或亚麻，`receiveShadow` |
| 图钉 | 小圆柱 + 球头，黄铜色，带微弱自发光以在暗面可见 |

**光照**
- `HemisphereLight` 做环境填充（暖天光 + 冷地光，强度低）
- 单个 `DirectionalLight` 做主光，暖色（约 `#ffd9a0`），**`castShadow: true`**——投影是"这是个实体物件"的关键证据
- 无第二光源。宁暗勿亮

**后期**
- 极轻的暗角 + 胶片颗粒
- **克制。** 目标是"一张静物摄影"，不是"游戏画面"

## 构图

- 地球仪占画面高度约 55–65%，略偏左下（符合三分法）
- 桌面在画面下 1/4 处形成水平分割
- 上方留空，供 UI 元素呼吸
- 相机默认 `fov 35`（略长焦，压缩透视，更像产品摄影）

## 地图贴图（程序化生成）

用 **Natural Earth 公有领域 GeoJSON**（`world-atlas` + `topojson-client`）在 canvas（4096×2048）上绘制：

1. 纸面底色（暖白）+ 极细噪点做纸纹
2. 陆地：低饱和填充 + 细墨线海岸线
3. 经纬网：极淡灰线（5° 或 15° 间隔）
4. 可选：国界（更淡）、主要城市点

→ `CanvasTexture` 贴到球体。**零版权风险、完全可控、可无限调风格。**

同一份 GeoJSON 顺便驱动图钉的经纬度定位。

## 降落过渡（本项目最抓人的一帧）

**纸面 → 实景** 的 shader 混合：

- 混合权重由相机高度驱动（`altitude: 2.5 → 0.05` 映射到 `mix: 0 → 1`）
- 两套贴图必须**做色彩归一化**（统一的亮度/对比度基准），否则过渡会显得廉价
- 混合带加**噪声扰动**，避免生硬的分界线
- **必须有降级开关**：调不好时退化为硬切 + 0.6s 交叉淡入

## 禁止事项

- ❌ 霓虹光、发光描边、赛博朋克配色
- ❌ 高饱和渐变背景
- ❌ 玻璃拟态 / 毛玻璃卡片
- ❌ 纯黑背景（用暖黑 `#14110e`）
- ❌ 无意义的粒子特效
- ❌ 圆角过大、阴影过重的"卡片式 UI"
